# 🎬 אולפן AI – סרטים, סדרות ומשחקים

אפליקציית דפדפן (בלי שרת) שבה:

1. **עלילה** – כותבים רעיון וה-AI כותב סרט או סדרה שלמים (ג׳מיני, או Pollinations החינמי בלי הרשמה, או מחולל מובנה בלי אינטרנט).
2. **דמויות** – מציירים כל דמות עם **ג׳מיני ננו בננה 🍌** (או Pollinations), עורכים תמונה קיימת בהוראה בטקסט, או מעלים תמונה משלכם.
3. **סצנות / פרקים** – עורכים קריינות ודיאלוג, ומציירים כל סצנה. ננו בננה מקבל את תמונות הדמויות כרפרנס, כך שהן נראות אותו דבר בכל סצנה.
4. **קולנוע** – הקרנה עם תנועת מצלמה, כתוביות, דיבוב קולי ומוזיקה, והקלטה לקובץ וידאו.
5. **משחק** – הופכים את הסרט להרפתקה אינטראקטיבית, משחק ארקייד או טריוויה, ומורידים כקובץ HTML לשיתוף.
6. **סטטיסטיקה** – כמה פעמים נפתח המשחק וכמה שחקנים שונים, דרך שירות מונה חינמי (Abacus / CounterAPI), בלי שרת משלכם.

## הפעלה
האתר: https://benzionbenaya4-collab.github.io/ai-studio/
אפשר להשתמש בכל מפתח AI: ג׳מיני (https://aistudio.google.com/apikey), Claude, ChatGPT/OpenAI, Groq, OpenRouter, DeepSeek, Mistral, Grok, Together או כל שירות תואם OpenAI – או בלי מפתח בכלל (Pollinations). מדביקים בהגדרות; המפתחות נשמרים רק בדפדפן ולא נכנסים לקבצי המשחק המשותפים.

## קבצים
- `index.html` – המבנה והעיצוב
- `app.js` – האפליקציה: AI, שמירה (IndexedDB), כל המסכים
- `player.js` – נגן הקולנוע והקלטת הווידאו
- `game-runtime.js` – מנוע המשחקים (עצמאי, מוטמע בקובץ המשחק המיוצא)
